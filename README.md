# WebmansCommands_Vanilla_Minecraft_PvP_System
A Player vs Player battle interface with kits!
Place the `datapacks` folder into your minecraft world's main folder

`War SystemV\datapacks\WarSystemV\data\ws\function\main.mcfunction` is the tick function that always runs
